# 温度读取修复

## 问题
模块显示温度 125°C，明显异常。

## 原因
原单位判定阈值 (200/2000) 不够准确，导致部分传感器数据被误判：
- 原始值 1250 被当作 0.1°C 单位直接读取 = 125.0°C
- 实际可能是 0.001°C 单位 (12.5°C) 或无效值

## 修复内容

### 1. 简化单位判定逻辑
| 原始值范围 | 处理方式 |
|-----------|----------|
| < 100 | 跳过 (无效值) |
| 100-999 | 视为 0.1°C 单位，直接使用 |
| ≥ 1000 | 视为 0.001°C 单位，除以 100 |

### 2. 新增温度合法性校验
- 有效范围: 10°C 到 60°C
- 超出范围的值会被过滤并记录日志警告

### 3. 新增调试命令
```sh
# 查看原始温度读数及转换结果
su -c "sh /data/adb/modules/battery-cooler/engine.sh temp_debug"
```

## 验证结果
- raw=350 → 35.0°C ✓
- raw=360 → 36.0°C ✓
- raw=1250 → 被过滤 (TOO_LOW) ✓
- raw=35500 → 35.5°C ✓
